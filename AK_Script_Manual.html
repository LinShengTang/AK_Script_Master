AK Script Manual｜腳本承諾兌現與留存診斷

Script 不是把話講完。它的任務是接住 Hook、維持留存、建立信任，並讓 CTA 成為合理下一步。

這份手冊的主要使用區是下方的 Script 快速診斷器。其他章節是查表與教學參考。

🚦這個工具怎麼用？

Step 1｜先填草稿

把 Hook 和 Script 前 10 秒貼進診斷器。這一步先不用追求完美。

Step 2｜看診斷

工具會判斷是否有承諾斷裂、自我介紹、過度承諾、缺信任或 CTA 鋪陳不足。

Step 3｜發布後回填數據

發布後再把前 10 秒留存、DM、互動等數據填回來，判斷下一支影片要修哪裡。

重要：本工具不是爆款保證器。它用來降低腳本犯錯率，尤其是避免 Hook 吸引人，但 Script 接不住。

01｜Script 是什麼？

白話版：Script 是影片的主體內容。它不是把所有資訊講完，而是讓觀眾相信「這支影片值得繼續看」，並自然走向下一步。

Script = 承諾兌現 + 留存維持 + 信任建立 + CTA 鋪陳
任務白話意思用來判斷什麼
承諾兌現Hook 說了什麼，Script 第一段就要回應。前 10 秒留存是否急墜。
留存維持讓觀眾中段不覺得無聊、混亂或被騙。Retention、AVD、Dips。
信任建立提供案例、過程、證據或真實經驗。互動品質、DM 意願。
CTA 鋪陳讓下一步行動變合理，而不是突然推銷。DM Count、收藏、點擊、留言品質。

02｜四段式 Script 結構

這張表怎麼用：寫腳本時從上到下檢查。不是每支影片都要一模一樣秒數，但每段任務都要存在。
段落白話意思常見錯誤修正方向
Anchor Beat
承接段		立刻接住 Hook 的問題。開始自我介紹、寒暄、講背景。第一句直接回應 Hook 關鍵字。
Trust Baseline
信任基線		給觀眾一個相信你的理由。只說觀念，沒有案例或證據。加入真實案例、過程、數據、踩過的錯。
Value Core
核心價值		交付一個明確收穫。太空泛或塞太多概念。一支影片只解一個具體問題。
Gap Open
行動鋪陳		留下合理下一步。看完就結束，或突然硬推銷。把完整清單、對照表、下一步診斷放到安全 CTA。

03｜Script 類型

這張表怎麼用：先選你的內容目的，再選 Script 類型。不要每支影片都用同一種結構。
類型適合目的適合 CTA風險
教學型快速提供方法，建立實用感。收藏型 / 延伸觀看型 / 私訊清單太完整會讓觀眾看完就走。
故事型建立信任，降低防禦。真實問題型 / 私訊承接型鋪陳太長會掉留存。
案例拆解型展示能力與證據。私訊承接型 / 申請型數據誇大會接近 Clickbait。
反直覺觀點型打破認知，製造注意力。討論型 / 收藏型 / 私訊型內容支撐不足會變標題黨。

04｜Script 與 Clickbait 邊界

核心規則：Hook、標題或封面承諾的內容，Script 必須提供對應內容。否則就不是「吸引人」，而是有 Clickbait 風險。
危險情況為什麼危險安全改法
Hook 說「一個錯誤讓你流量歸零」，Script 卻講心態。承諾和內容斷裂。第一段直接指出那個具體錯誤。
Hook 承諾具體數字，但沒有證據。容易被視為誇大。補案例背景、數據來源或改成個人經驗。
標題很刺激，但內容很普通。可能出現高 CTR + 低 Retention。降低標題承諾，讓內容能兌現。

06｜Script 發布前檢查清單

承諾與留存

  • Hook 承諾是否在前 10 秒被接住？
  • 前 10 秒是否避免自我介紹、寒暄、抽象鋪陳？
  • Script 是否只解決一個具體問題？
  • 中段是否有明確價值，而不是空泛說教？

信任與 CTA

  • 是否至少有一個 Trust Signal？
  • 是否避免誇大數據與保證結果？
  • CTA 前是否有合理鋪陳？
  • CTA 是否符合 CTA Safety Patch v1.1？

📘 名詞快查

Anchor Beat

Hook 後第一段，用來接住開頭承諾。白話：不要讓觀眾覺得被騙。

Trust Signal

讓觀眾相信你的證據，例如案例、過程、經驗、數據。

Value Core

影片中段真正交付價值的部分。白話：這支影片到底讓人得到什麼。

Gap Open

結尾前留下合理下一步，不是故意騙，而是把完整清單、工具或診斷留給 CTA。

Retention Dips

留存曲線突然掉下去。通常代表那個秒數附近有廢話、混亂、斷裂或資訊過載。

AVD

Average View Duration，平均觀看時長。用來看觀眾平均看多久。

CTA Paving

CTA 鋪陳。讓觀眾覺得下一步是自然延伸，而不是突然被推銷。

Audience Mismatch

受眾錯位。影片吸引到的人不是你真正想服務的人。

Platform Safety｜Claim Delivery Guard

Script 的安全任務，是兌現 Hook 承諾，不讓內容變成標題黨、空話或無證據成效宣稱。

發布前檢查

  • Hook 提出的問題，Script 是否真的回答？
  • 標題 / 縮圖 / 第一秒是否在影片中被兌現？
  • 是否使用「保證、必爆、月入、幾天漲粉」等無證據承諾？
  • 是否把 practical_inference 說成 official？

安全改寫

高風險：照做 3 天漲粉 1000。 安全版：這 3 個檢查點能幫你判斷內容是否卡在第一句、主題錨點或受眾代入。
